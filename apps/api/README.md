# API App (NestJS)

Sprint 1 runnable API scaffold with:
- Auth endpoints (`register`, `login`, `profile`)
- JWT + RBAC guard/decorator skeleton
- Programs listing endpoint
- Applicant draft/submit/list endpoints
- Remita initiate/verify/webhook mock adapter endpoints

## Run
```bash
npm run dev --workspace @fudma/api
```

## Base URL
`http://localhost:4000/api/v1`
